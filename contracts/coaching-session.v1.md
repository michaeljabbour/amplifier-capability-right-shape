# Optional coaching session, version 1

`coaching-session/v1` is an optional local documentation convention, independent of runtime APIs and existing Taste improvement-round or Worth Using record versions. It adds no command, provider, persistent agent, permission or mandatory service. Each capability keeps its own promise and can be used alone.

When a person explicitly wants practice, agree the named user/job, observable goal, starting artifact and baseline, scope/time/round budget, what must survive and a domain-specific feedback checkpoint. Let the person attempt a consequential judgment before diagnostic feedback when appropriate. Keep native execution direct; operational tools get optional pre/post checkpoints, never a conversational wrapper around their API. Market Fit remains its existing coached method; Worth Using keeps Score/Coach; Taste keeps its two-round default. Their native question cadence and budgets win. Technical retries and human practice rounds are different budgets.

Stop at the target, user stop at any time, agreed cap, a stalled/no-meaningful-gain attempt, missing input/authority or critical fail/unknown. Stop teaching when the person says “just finish”; do only the already authorized task. Preserve the baseline and present keep/revert/leave-unchanged for human review. A record cannot authorize an edit, upload, purchase, provider call or publication. Preserve core safety/correctness/accessibility gates, unknowns and native verifiers.

The minimum record fields are: `user_job`, `goal`, `starting_artifact`, `baseline`, `scope`, `budget`, `preserve`, `feedback_checkpoint`, `stop` (including user stop anytime), `decision` and `human_review`. The closed v1 JSON schema additionally makes optional recording and growth status explicit. The record is optional: a normal request needs neither a form nor a stored trace. Save nowhere by default. If the person explicitly opts in, retain the smallest task-only record at their chosen private location for an agreed retention period. Do not collect intimate disclosure, standing memory, transcripts or credentials as a side effect. User-provided content remains under its own rights and privacy constraints.

Quote/attribute only actual human attempts and reasons; keep observed dips without interpreting them as guaranteed progress. A fictional example or unattended agent run cannot establish growth. If no person is available, return a proposal, assumptions and unanswered questions. Usefulness keeps Job/First value/Fit/Outcome/Trust/Return separate. Team/agent walkthroughs stay Claimed; Seen and Repeated need authentic dated outside-user evidence, with unprompted return for Repeated. No aggregate learner score or portfolio usefulness claim follows.

The schema and central validation fixtures check documentation metadata only. They do not prove truth, consent, efficacy or runtime authorization. Independent operator context must supply allowed artifacts, round ceiling and any accepted review/evidence references. A record cannot enlarge those limits. Existing manifests, method IDs, imports, native tools and old closed schema versions remain unchanged. A capability's compact local guide is sufficient without downloading this schema or installing another capability.
